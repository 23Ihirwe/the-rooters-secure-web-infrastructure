THE ROOTERS - GROUP 06
FIREWALL RULES
Web Infrastructure Summative Assignment

Firewall: UFW (Uncomplicated Firewall)

==================================================
1. DEFAULT FIREWALL POLICY
==================================================

sudo ufw default deny incoming
sudo ufw default allow outgoing

==================================================
2. REQUIRED ALLOW RULES
==================================================

sudo ufw allow 22/tcp
sudo ufw allow 80/tcp
sudo ufw allow 443/tcp

Port purposes:

22/tcp  - SSH administration
80/tcp  - HTTP entry point used by NGINX for HTTP-to-HTTPS redirection
443/tcp - HTTPS secure web entry point

==================================================
3. ENABLE FIREWALL
==================================================

sudo ufw enable

==================================================
4. FINAL FIREWALL VERIFICATION
==================================================

sudo ufw status numbered

Final allowed ports:

22/tcp    ALLOW IN
80/tcp    ALLOW IN
443/tcp   ALLOW IN

IPv6 equivalents may also appear:

22/tcp (v6)    ALLOW IN
80/tcp (v6)    ALLOW IN
443/tcp (v6)   ALLOW IN

==================================================
5. BACKEND PORT EXPOSURE
==================================================

Backend 1: 127.0.0.1:3001
Backend 2: 127.0.0.1:3002

Ports 3001 and 3002 are NOT included in the public
UFW allow list.

Verification:

sudo ufw status numbered
ss -ltnp | grep -E '3001|3002'

The backend services are bound to the loopback address
127.0.0.1. Clients access the infrastructure through
NGINX rather than directly through backend ports
3001 and 3002.

==================================================
6. ALLOWED CONNECTION VERIFICATION
==================================================

HTTPS test:

curl -sk https://localhost

HTTP-to-HTTPS redirect test:

curl -I http://localhost

Expected HTTP result:

HTTP/1.1 301 Moved Permanently
Location: https://localhost/

==================================================
7. FIREWALL POLICY SUMMARY
==================================================

The final UFW configuration follows the principle of
least exposure.

Only ports 22, 80 and 443 are permitted for required
administration and web functions.

Backend ports 3001 and 3002 are not included in the
public UFW allow rules and the backend services are
bound to 127.0.0.1 behind NGINX.
